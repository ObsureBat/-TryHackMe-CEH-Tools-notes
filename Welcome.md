## 20-Day Smart Plan (realistic, not overload)

### 🗓️ Days 1–5: Foundations + Speed

- Revise **nmap deeply**
    
- Practice scanning multiple machines
    
- Learn **output interpretation**
    
- Metasploit basics every day
    

⏱️ 5–6 hrs/day is enough if focused

---

### 🗓️ Days 6–10: Web & Password Attacks

- sqlmap hands-on daily
    
- dirb / gobuster practice
    
- Hydra on:
    
    - SSH
        
    - HTTP login forms
        
- Crack hashes with John
    

👉 Use:

- DVWA
    
- bWAPP
    
- Metasploitable2
    

---

### 🗓️ Days 11–15: Exploitation & Post-Exploitation

- Metasploit labs daily
    
- Practice:
    
    - Getting meterpreter
        
    - Dumping hashes
        
    - Reading flags
        
- Try **privilege escalation basics**
    

---

### 🗓️ Days 16–18: Full Mock Practice

- Simulate exam:
    
    
    - Time yourself
        
    - No notes initially
        
- Repeat weak areas
    
- Memorize **common commands**
    

---

### 🗓️ Days 19–20: Revision Only

- No new topics ❌
    
- Command cheat sheets
    
- Calm practice
    
- Sleep properly 😴
