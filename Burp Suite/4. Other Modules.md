# 🧠 Burp Suite: Other Modules (Quick Revision Notes)

---

## 📌 Overview

Burp Suite includes several **lesser-known but powerful modules**:

- 🔓 **Decoder** → Encode/Decode & Hash data
    
- 🔍 **Comparer** → Compare requests/responses
    
- 🎲 **Sequencer** → Analyze randomness (entropy)
    
- 🗂️ **Organizer** → Store & manage requests
    

💡 These tools **save time + improve efficiency** during pentesting.

---

# 🔐 1. Decoder

## 🔹 Purpose

- Encode / Decode data
    
- Generate **hashes**
    
- Auto-decode unknown data (**Smart Decode**)
    

---

## 🔹 Features

### 🧾 Encoding / Decoding Types

- **URL Encoding** → `%2F`
    
- **HTML Encoding** → `&amp;`
    
- **Base64**
    
- **ASCII Hex** → text → hex
    
- **Binary / Octal / Hex**
    
- **Gzip Compression**
    

---

## 🔹 Smart Decode

- Automatically decodes **multi-layer encoded data**
    

✔ Example:

```
&#x42;&#x75;&#x72;&#x70;
→ Burp
```

---

## 🔹 Hex View

- Edit **byte-level data**
    
- Useful for:
    
    - Binary files
        
    - Low-level manipulation
        

---

## 🔹 Hashing

### 📌 Concept

- One-way function → irreversible
    
- Used for:
    
    - Password storage
        
    - File integrity
        

### ⚠️ Important

- ❌ MD5 → Deprecated
    
- ✅ Use stronger hashes like SHA-256
    

---

## 🔹 Use Cases

- Decode payloads
    
- Encode attack payloads
    
- Verify file integrity
    
- Crack/identify hashes

# 🎲 3. Sequencer

## 🔹 Purpose

Analyze **randomness (entropy)** of tokens

---

## 🔹 What are Tokens?

- Session cookies
    
- CSRF tokens
    
- Password reset tokens
    

---

## 🔹 Why Important?

Weak randomness = predictable tokens = **security risk**

---

## 🔹 Modes

### 🔄 Live Capture

- Sends thousands of requests
    
- Collects tokens automatically
    

### 📂 Manual Load

- Load pre-collected tokens
    

---

## 🔹 Key Metrics

- **Entropy (bits)** → randomness level
    
- **Reliability (%)** → confidence
    
- **Overall Rating** → e.g., _Excellent_
    

---

## 🔹 Example Insight

- 117-bit entropy → **Strong & secure**
    
- Low entropy → **vulnerable to prediction**
    

---

## 🔹 Use Cases

- Test session security
    
- Detect weak token generation
    
- Analyze CSRF protection
    

---

---

---

## 🔹 Use Cases

- Organize pentesting workflow
    
- Prepare reports

# 🧩 Exam Tips / Key Points

- **Decoder → Smart Decode = auto decode**
    
- **Comparer → Words vs Bytes**
    
- **Sequencer → Measures entropy**
    
- **Organizer → Read-only storage**
    
- **MD5 is insecure**
    
- **High entropy = secure tokens**
