# 🛠️ Burp Suite Basics (CEH Practical Notes)

## 📌 What is Burp Suite?

- **Java-based web pentesting framework**
    
- Used for:
    
    - Web apps
        
    - Mobile apps
        
    - APIs
        
- Core function:
    
    - Intercept, modify HTTP/HTTPS traffic
        

---

## 🧠 Core Concept (VERY IMPORTANT)

```
Browser ⇄ Burp Proxy ⇄ Web Server
```

### 🔥 Key Capability:

- Intercept requests before reaching server
    
- Modify responses before reaching browser
    

---

## 🧩 Burp Editions

|Edition|Features|
|---|---|
|Community|Free, limited tools|
|Professional|Scanner, Intruder unlimited, extensions|
|Enterprise|Runs on server, continuous scanning|

👉 **Exam Question**

- Server-based continuous scanning → **Enterprise**
    

---

## ⚙️ Burp Tools (MOST IMPORTANT)

### 1. Proxy ⭐

- Intercepts requests/responses
    
- Modify traffic
    

### 2. Repeater

- Send same request multiple times
    
- Used for:
    
    - SQLi testing
        
    - Payload testing
        

### 3. Intruder

- Brute force / fuzzing
    
- Example:
    
    - Login attack
        

### 4. Decoder

- Encode/Decode:
    
    - URL
        
    - Base64
        

### 5. Comparer

- Compare responses/data
    

### 6. Sequencer

- Check randomness (tokens, cookies)
    

---

## 🧠 Tool Usage Summary (Exam Ready)

|Task|Tool|
|---|---|
|Intercept traffic|Proxy|
|Brute force login|Intruder|
|Repeat request|Repeater|
|Encode payload|Decoder|
|Compare data|Comparer|
|Check randomness|Sequencer|

## 🌍 Browser Setup (FoxyProxy)

### Config:

```
IP: 127.0.0.1
Port: 8080
```

### Steps:

1. Install FoxyProxy
    
2. Add proxy
    
3. Enable proxy
    
4. Turn ON intercept
    

---

## ⚠️ Important Notes

- If intercept ON → browser will hang
    
- Always turn OFF after use


---

## 🔐 HTTPS Proxy Fix

### Problem:

Browser doesn’t trust Burp CA

### Solution:

1. Visit:
    

```
http://burp/cert
```

2. Download certificate
    
3. Import into browser
    
4. Trust certificate

## 🧪 XSS Attack Example (IMPORTANT)

### Payload:

```html
<script>alert("Successful XSS")</script>
```

### Steps:

1. Intercept request
    
2. Replace input field
    
3. URL encode
    

```
Shortcut: Ctrl + U
```

4. Forward request
