# 🧠 Burp Suite: Extensions (Quick Revision Notes)

---

## 📌 Overview

- Burp Suite supports **modular extensibility**
    
- Extensions **enhance functionality** beyond default features
    
- Can be:
    
    - Installed from **BApp Store**
        
    - Added manually (custom extensions)
        

💡 Makes Burp highly **customizable for pentesting**

---

# 🔌 1. Extensions Interface

## 🔹 Purpose

Manage all installed extensions

---

## 🔹 Components

### 📋 Extensions List

- Shows all installed extensions
    
- Can:
    
    - Enable / Disable
        

---

### ⚙️ Management Options

- **Add** → Install extension manually
    
- **Remove** → Uninstall extension
    
- **Up / Down** → Change execution order
    

---

## 🔹 Execution Order

⚠️ **Important:**

- Extensions run in **Descending Order (Top → Bottom)**
    

💡 Order matters because:

- Extensions may **modify requests**
    
- Conflicts can occur
    

---

## 🔹 Extension Details Panel

- **Details** → Name, version, description
    
- **Output** → Logs/results
    
- **Errors** → Debugging info
    

---

# 🏪 2. BApp Store

## 🔹 Purpose

Official marketplace for Burp extensions

---

## 🔹 Features

- Easy installation
    
- Verified extensions
    
- Search & explore tools
    

---

## 🔹 Supported Languages

- **Java (native)**
    
- **Python (via Jython)**
    
- **Ruby (via JRuby)**
    

---

## 🔹 Example Extension

### ⏱️ Request Timer

- Measures request-response time
    
- Useful for:
    
    - Time-based attacks
        
    - Username enumeration
        

---

## 🔹 Installation Steps

1. Go to **BApp Store tab**
    
2. Search extension
    
3. Click **Install**
    
4. New tab/feature appears
    

---

# 🐍 3. Jython Integration

## 🔹 Purpose

Run **Python-based extensions**

---

## 🔹 What is Jython?

- Java implementation of Python
    
- Required for Python extensions in Burp
    

---

## 🔹 Setup Steps

1. Download **Jython standalone JAR**
    
2. Go to:
    
    - Extensions → Settings
        
3. Set JAR file path
    

---

## 🔹 Importance

- Unlocks **many Python extensions**
    
- Expands capabilities significantly
    

---

# 🧩 4. Burp Suite API

## 🔹 Purpose

Allows developers to create custom extensions

---

## 🔹 Access

- Extensions → **APIs tab**
    

---

## 🔹 Capabilities

- Interact with:
    
    - Requests & responses
        
    - Proxy
        
    - Scanner
        
- Build automation tools
    

---

## 🔹 Supported Languages

- **Java (best support)**
    
- **Python (Jython)**
    
- **Ruby (JRuby)**
    

---

## 🔹 Use Cases

- Custom scanners
    
- Automation scripts
    
- Advanced payload manipulation
    

---

# ⚡ Key Concepts Summary

|Feature|Description|
|---|---|
|Extensions|Add new functionality|
|BApp Store|Install ready-made extensions|
|Jython|Enables Python support|
|API|Build custom extensions|

---

# 🧩 Exam Tips / Key Points

- Extensions run in **Descending Order**
    
- BApp Store = **official extension source**
    
- **Jython required for Python**
    
- Extensions can:
    
    - Add tabs
        
    - Modify requests
        
    - Automate attacks
        
- API allows **deep customization**
    

---

# 🚀 When to Use Extensions

- Need automation → Intruder alternatives
    
- Need advanced testing → custom tools
    
- Need efficiency → pre-built extensions
