# Task 1 — Nmap Scan Detection

## Detect TCP Connect Scans

### Filter

```wireshark
tcp.flags.syn==1 and tcp.flags.ack==0 and tcp.window_size > 1024
```

## Explanation

|Filter|Meaning|
|---|---|
|`tcp.flags.syn==1`|SYN packets only|
|`tcp.flags.ack==0`|Ignore ACK packets|
|`tcp.window_size > 1024`|Typical TCP connect scan behavior|

## Key Finding

- Total TCP Connect scans → `1000`
    

---

## Identify UDP Closed Ports

### Filter

```wireshark
icmp.type==3 and icmp.code==3
```

## Explanation

|Field|Meaning|
|---|---|
|`icmp.type==3`|Destination unreachable|
|`icmp.code==3`|Port unreachable|

## Key Finding

- UDP closed port messages → `1083`
    

---

## Detect Open UDP Port in Range

### Filter

```wireshark
udp.port in {55 .. 70}
```

## Key Finding

- Open UDP port → `68`
    

---

# CEH Quick Notes — Nmap Scan Indicators

|Scan Type|Detection|
|---|---|
|TCP Connect|SYN + ACK responses|
|SYN Scan|SYN without full handshake|
|UDP Scan|ICMP Port Unreachable|
|Xmas Scan|FIN + PSH + URG flags|
|NULL Scan|No flags set|

# Task 2 — ARP Poisoning & MITM

## Detect ARP Poisoning Requests

### Filter

```wireshark
(arp.dst.hw_mac == 00:00:00:00:00:00) && (arp.src.hw_mac == 00:0c:29:e2:18:b4)
```

## Explanation

|Value|Meaning|
|---|---|
|`00:00:00:00:00:00`|Broadcast/unknown target|
|Source MAC|Attacker MAC|

## Key Finding

- ARP requests crafted by attacker → `284`
    

---

## Detect HTTP Packets Received by Attacker

### Filter

```wireshark
eth.dst == 00:0c:29:e2:18:b4 and http
```

## Key Finding

- HTTP packets sniffed → `90`
    

---

## Detect Sniffed Credentials

### Filter

```wireshark
((eth.dst == 00:0c:29:e2:18:b4 and http)) && (urlencoded-form.key == "pass")
```

## Key Finding

- Username/password entries → `6`
    
## What is the comment provided by the "Client354"?

### Filter

```wireshark
http contains Client354
```

## Credential Discovery

### Important Technique

1. Open POST request
    
2. Expand:
    

```text
HTML Form URL Encoded
```

3. Look for:
    

```text
uname=
pass=
```
