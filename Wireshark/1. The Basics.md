# 🔬 Packet Dissection (MOST IMPORTANT)

---

## 🧠 OSI Layer Mapping in Wireshark

---

### 🧩 Diagram: Packet Layers

```
Frame (Layer 1)
 ↓
MAC (Layer 2)
 ↓
IP (Layer 3)
 ↓
TCP/UDP (Layer 4)
 ↓
Application (Layer 7)
 ↓
Data
```

---

## 📌 Layer Breakdown

---

### 1️⃣ Frame Layer

- Packet number
    
- Capture info
    

---

### 2️⃣ MAC Layer

- Source MAC
    
- Destination MAC
    

---

### 3️⃣ IP Layer

- Source IP
    
- Destination IP
    
- TTL
    

---

### 4️⃣ Transport Layer

- TCP / UDP
    
- Ports
    
- Payload size
    

---

### 5️⃣ Application Layer

- HTTP / FTP / SMB
    
- Headers + data
    

---

# 🔎 Packet Filtering (CORE SKILL)

---

## 🧠 Types

|Type|Use|
|---|---|
|Capture Filter|Before capture|
|Display Filter|After capture|

---

## 🔥 Basic Filters

---

### 🌐 Protocol Filter

```bash
http
dns
ftp
```

---

### 🔌 Port Filter

```bash
tcp.port == 80
udp.port == 53
```

---

### 🌍 IP Filter

```bash
ip.addr == 192.168.1.1
```

---

## 🧩 Diagram: Filtering

```
All Packets → Apply Filter → Reduced Packets
```
