## WHOIS – Domain & IP Information

> **Purpose:** Identify domain owner, registrar, IP range, organization

### Basic WHOIS

```bash
whois example.com
```

### WHOIS for IP Address

```bash
whois 8.8.8.8
```

### Common Information Found

- Organization name
    
- Country
    
- IP range
    
- Email contacts
    

**Exam Tip:** Useful in recon phase to identify target organization & network scope.
