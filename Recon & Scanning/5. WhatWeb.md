## WhatWeb – Web Technology Fingerprinting

> **Purpose:** Identify CMS, frameworks, server, plugins

### Basic Scan

```bash
whatweb http://example.com
```

### Verbose Mode

```bash
whatweb -v http://example.com
```

### Aggressive Scan

```bash
whatweb -a 3 http://example.com
```

### Scan Multiple Targets

```bash
whatweb targets.txt
```

### Output to File

```bash
whatweb http://example.com --log-verbose=whatweb.txt
```

### Information Discovered

- CMS (WordPress, Joomla)
    
- Server (Apache, Nginx)
    
- Frameworks (PHP, React)
    
- Analytics & plugins
    

**Exam Tip:** Run before web attacks (SQLi, XSS) to understand target stack.
