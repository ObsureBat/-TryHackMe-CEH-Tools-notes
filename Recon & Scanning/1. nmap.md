# Nmap

> **Purpose:** Network discovery, port scanning, service & OS detection, enumeration, firewall evasion

---

## 1. Target Specification

### Single / Multiple Targets

- `nmap 192.168.1.10`
    
- `nmap 192.168.1.10 192.168.1.20`
    
- `nmap example.com`
    

### Ranges & Subnets

- `nmap 192.168.1.1-254`
    
- `nmap 192.168.1.0/24`
    

### Input from File

- `nmap -iL targets.txt`
    
- Exclude hosts: `nmap 192.168.1.0/24 --exclude 192.168.1.5`
    

### Random Targets

- `nmap -iR 100`
    

---

## 2. Host Discovery (Ping Scans)

> Used to find **live hosts** before port scanning

- `-sn` → Ping scan only (no ports)
    

```bash
nmap -sn 192.168.1.0/24
```

- `-Pn` → Skip ping (assume host is up)
    

```bash
nmap -Pn 192.168.1.10
```

- ICMP Echo Ping
    

```bash
nmap -PE 192.168.1.0/24
```

- TCP SYN Ping
    

```bash
nmap -PS22,80 192.168.1.0/24
```

- TCP ACK Ping
    

```bash
nmap -PA80 192.168.1.0/24
```

- UDP Ping
    

```bash
nmap -PU53 192.168.1.0/24
```

- ARP Ping (Local Network – Very Reliable)
    

```bash
nmap -PR 192.168.1.0/24
```

- Disable DNS Resolution (faster)
    

```bash
nmap -n 192.168.1.0/24
```

## 3. Port Scanning

### TCP Scans

- **SYN Scan (Stealth, Default)**
    

```bash
nmap -sS 192.168.1.10
```

- **TCP Connect Scan** (No root)
    

```bash
nmap -sT 192.168.1.10
```

### Port Selection

- Specific ports
    

```bash
nmap -p 22,80,443 192.168.1.10
```

- Port range
    

```bash
nmap -p 1-65535 192.168.1.10
```

- Fast scan (Top 100 ports)
    

```bash
nmap -F 192.168.1.10
```

### UDP Scan (Slow but Important)

```bash
nmap -sU 192.168.1.10
```

- TCP + UDP Combined
    

```bash
nmap -sS -sU -p T:1-1000,U:53,161 192.168.1.10
```

## 7. NSE (Nmap Scripting Engine)

### Default Scripts

```bash
nmap -sC 192.168.1.10
```

### Specific Scripts

- HTTP Enumeration
    

```bash
nmap -p 80 --script http-enum 192.168.1.10
```

- HTTP Title
    

```bash
nmap --script http-title -p80 192.168.1.10
```

- FTP Anonymous Login
    

```bash
nmap -p 21 --script ftp-anon 192.168.1.10
```

- SMB Enumeration
    

```bash
nmap -p 445 --script smb-enum-shares,smb-os-discovery 192.168.1.10
```

- DNS Brute Force
    

```bash
nmap --script dns-brute example.com
```

## 8. Firewall / IDS Evasion

- Packet Fragmentation
    

```bash
nmap -f 192.168.1.10
```

- Custom MTU
    

```bash
nmap --mtu 32 192.168.1.10
```

- Decoy Scan
    

```bash
nmap -D 192.168.1.101,ME,192.168.1.102 192.168.1.10
```

- Source Port Spoofing
    

```bash
nmap -g 53 192.168.1.10
```

- Source IP Spoofing
    

```bash
nmap -S 10.0.0.5 192.168.1.10
```

- Add Random Data
    

```bash
nmap --data-length 200 192.168.1.10
```

- Slow Timing (IDS Evasion)
    

```bash
nmap -T0 192.168.1.10
```

## 9. Output & Reporting

- Normal Output
    

```bash
nmap -oN scan.txt 192.168.1.10
```

- XML Output
    

```bash
nmap -oX scan.xml 192.168.1.10
```

- Grepable Output
    

```bash
nmap -oG scan.gnmap 192.168.1.10
```

- All Formats
    

```bash
nmap -oA results 192.168.1.10
```

- Append Results
    

```bash
nmap --append-output -oN scan.txt 192.168.1.10
```

- Show Only Open Ports
    

```bash
nmap --open 192.168.1.10
```

---

## 10. Useful Exam Combos

- Full Recon Scan
    

```bash
nmap -sS -sV -O -sC -p- 192.168.1.10
```

- Stealth + Evasion
    

```bash
nmap -sS -T0 -f --data-length 100 -D ME,192.168.1.5 192.168.1.10
```

---

## CEH Practical Tips

- Always start with **host discovery**
    
- Use `-Pn` if ping is blocked
    
- SYN scan + version detection = most answers
    
- NSE scripts give quick wins
    
- Save output for proof
