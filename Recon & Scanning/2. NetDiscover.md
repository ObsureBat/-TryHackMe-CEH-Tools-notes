## Netdiscover – Network Discovery

> **Purpose:** Discover live hosts on local network using ARP (very fast & reliable)

### Basic Scan

```bash
netdiscover
```

### Scan Specific Interface

```bash
netdiscover -i eth0
```

### Scan Specific Range

```bash
netdiscover -r 192.168.1.0/24
```

### Passive Mode (Stealth)

```bash
netdiscover -p
```

### Output to File

```bash
netdiscover -r 192.168.1.0/24 -o netdiscover.txt
```

**Exam Tip:** Best tool for finding targets in LAN labs quickly before Nmap.
